# Contributing to git-summary

Thank you for your interest in contributing!

## Setup

1. Clone the repository
   git clone https://github.com/anushri-dilip/git-summary.git
   cd git-summary

2. Create and activate a virtual environment
   python3 -m venv venv
   source venv/bin/activate

3. Install in editable mode
   pip install -e .

4. Run the tool
   git-summary

## Making Changes

- Create a new branch for your change: `git checkout -b feature/your-feature`
- Make your changes and commit them with a clear message
- Push your branch and open a Pull Request against `main`
- Reference any related issue in your PR description (e.g. `Closes #5`)

## Code Style

- Follow standard Python conventions (PEP 8)
- Keep functions small and focused
- Test your changes manually before submitting

## Reporting Issues

Open an issue on GitHub with a clear description of the bug or feature request.
